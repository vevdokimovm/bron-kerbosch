# bron-kerbosch

Алгоритм Брона — Кербоша: поиск всех максимальных клик в графе, базовая и оптимизированная версия с опорной вершиной

**Стек:** `Python 3.10+` · `NetworkX` · `Matplotlib`

## Чем показателен

Нетривиальный алгоритм с доказанной оценкой сложности и разбором оптимизации — противовес прикладным сервисам в остальной витрине.

## Что внутри

- **Две версии рядом** — базовая рекурсия и вариант с опорной вершиной, чтобы разница в числе вызовов была видна, а не заявлена
- **Оценка сложности честная** — O(3^(n/3)) для базовой; выигрыш опорной вершины практический, а не асимптотический, и в README так и написано
- **Визуализация найденных клик** через NetworkX и Matplotlib
- **Курсовая работа с разбором** — `coursework-bron-kerbosch-ru.docx`: постановка, доказательство корректности, замеры на графах разного размера

## Как это опубликовано

Публичное зеркало приватного ядра. Ядро живёт в закрытом репозитории,
сюда переносится **только то, что явно внесено в белый список** — не «всё, кроме
исключений»: чёрные списки протекают, и одного забытого шаблона хватает,
чтобы уехало лишнее. Публикация идёт скриптом, перед пушем прогоняется
секрет-сканер. Решение и его основания — ADR-009 в системе репозиториев автора.
